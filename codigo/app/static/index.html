      Cómo obtener la clave de API de cada proveedor
      
      
      La clave es como una contraseña: se ve completa una sola vez al crearla. Cópiela, péguela aquí en «Clave de API» y no la envíe por correo ni chat. Todos los proveedores cobran por uso: hay que cargar saldo o un medio de pago en su consola.
      
      
      Claude (Anthropic)
        
        
      1. Entre a console.anthropic.com y cree una cuenta (o ingrese con la del despacho).
        2. 
        
      2. En Billing agregue un medio de pago o compre créditos.
        3. 
        
      3. Vaya a Settings → API Keys y pulse Create Key. Póngale un nombre (por ejemplo «LCCOUNTER»).
        4. 
        
      4. Copie la clave (empieza por sk-ant-). Aquí: plantilla «Claude (Anthropic)», pegue la clave y guarde.
      
      
      DeepSeek
        
        
      1. Entre a platform.deepseek.com y cree una cuenta.
        2. 
        
      2. En Top up cargue saldo.
        3. 
        
      3. En API keys pulse Create new API key y cópiela (empieza por sk-).
        4. 
        
      4. Aquí: plantilla «DeepSeek» (la URL base se llena sola), pegue la clave y escriba el modelo tal como aparece en la documentación de DeepSeek.
      
      
      OpenAI
        
        
      1. Entre a platform.openai.com y cree una cuenta de organización.
        2. 
        
      2. En Settings → Billing agregue un medio de pago o saldo.
        3. 
        
      3. En API keys pulse Create new secret key y cópiela (empieza por sk-).
        4. 
        
      4. Aquí: plantilla «OpenAI», pegue la clave y escriba el modelo que vaya a usar.
      
      
      Sin internet: Ollama en este Mac (no necesita clave)
        
        
      1. Ya está instalado con el modelo qwen3:8b y asignado a Auditin. Los datos no salen del equipo.
        2. 
        
      2. Para otro modelo: en la Terminal, ollama pull nombre-del-modelo, y agréguelo aquí en el proveedor «Ollama (local, sin internet)».
        3. 
        
      3. Ollama debe estar abierto (ícono de la llama en la barra de menú) para que Auditin responda.
      
      
      Después de guardar un proveedor, use «Probar» y asígnelo en «Qué proveedor usa cada función».

      Automejora recursiva (RSI)
      
      
      Nivel 1: genera plantillas de opinión candidatas, las mide contra cómo escribe realmente el revisor (con un caso reservado para la prueba) y solo conserva las que mejoran. Nivel 2 (recursivo): con los resultados reescribe su propia estrategia de mejora; la nueva estrategia compite con la vigente y solo la reemplaza si gana. Nunca modifica cálculos, reglas de validación ni código; todo queda versionado y es reversible.
      
      
      
        
        
        
        
        
      El ciclo corre solo todos los días a esta hora si la app está encendida (si estaba apagada, corre al encenderla ese día). La mejora aplica al sistema (plantillas de opinión y su estrategia; los mapeos y reglas los mejora la mejora continua con aprobación del revisor) y nunca a informes ya validados, que quedan congelados.

      Tiempos y registro
      Cuánto tiempo está cada usuario en línea, cuánto tarda el procesamiento de cada cliente y qué hizo cada quién.
      
    
      
      
      Tiempo en línea por usuario
      Cuenta solo mientras la aplicación está abierta y visible.
      
      
      Tiempo de procesamiento por cliente
      Desde que se lee el Excel hasta que el informe queda listo para el revisor (última validación de cada periodo).
